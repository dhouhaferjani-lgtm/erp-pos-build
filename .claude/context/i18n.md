# Internationalization (i18n) Reference

## Supported Languages

- **English (en)** — Default fallback
- **French (fr)** — Primary target market
- **Arabic (ar)** — RTL support ready (future)

## Frontend (React)

**Library:** `react-i18next` with `i18next-browser-languagedetector`

**Translation files:** `apps/web/src/locales/{lang}/{namespace}.json`

```
apps/web/src/locales/
├── en/
│   ├── common.json      # Shared UI strings
│   ├── auth.json        # Authentication
│   ├── sales.json       # Partners, documents, quotes
│   ├── inventory.json   # Products, stock
│   ├── treasury.json    # Payments, instruments
│   └── validation.json  # Form validation
│   └── ...               # (subset — see i18n.ts for full namespace list)
├── fr/
│   └── (same structure)
└── ar/
    └── (same structure)
```

**Usage pattern:**
```tsx
const { t } = useTranslation(['common', 'sales'])
<h1>{t('common:appName')}</h1>
<label>{t('sales:partners.name')}</label>
```

**Language switching:**
```typescript
import { languages } from '../lib/i18n'
i18n.changeLanguage('fr')
```

## RTL-Ready Tailwind Properties

Always use logical properties instead of directional:

| Use this | Not this |
|----------|----------|
| `ms-*` / `me-*` | `ml-*` / `mr-*` |
| `ps-*` / `pe-*` | `pl-*` / `pr-*` |
| `start-*` / `end-*` | `left-*` / `right-*` |
| `text-start` / `text-end` | `text-left` / `text-right` |
| `border-s-*` / `border-e-*` | `border-l-*` / `border-r-*` |
| `rounded-s-*` / `rounded-e-*` | `rounded-l-*` / `rounded-r-*` |

## Backend (Laravel)

**Translation files:** `apps/api/lang/{lang}/{file}.php`

**Locale detection:** `SetLocale` middleware reads `X-Language` header (priority) > `Accept-Language` header > default locale. Response includes `Content-Language` header.

**Usage:**
```php
__('messages.created', ['resource' => 'Partner'])
// Validation messages auto-translated via lang/{lang}/validation.php
```

## Key Naming Convention

```
{namespace}.{feature}.{element}

common.save, common.cancel, common.delete, common.noData
sales.invoices.title, sales.invoices.create
inventory.products.title, inventory.stockLevels.title
finance.chartOfAccounts.title, finance.reports.trialBalance
settings.company.title, settings.subscription.title
```

## When Creating New Components

1. Identify all user-facing text
2. Add keys to `en/{namespace}.json` first
3. Use `t('namespace:key')` in component
4. Add French translation to `fr/{namespace}.json`
5. Add Arabic placeholder to `ar/{namespace}.json` (if exists)

## Pre-Commit i18n Checklist

- [ ] No hardcoded user-facing text in TSX files
- [ ] All new keys added to en JSON
- [ ] French translations added to fr JSON
- [ ] Test RTL layout by switching to Arabic
