# Manual Migrations

Migrations in this directory are **NOT** picked up by `php artisan migrate` because Laravel's migrator only scans the direct contents of `database/migrations/`, not subdirectories.

## When to add a migration here

Use `manual/` for migrations that need owner sign-off before running in any environment, e.g.:

- Backfills that touch already-signed fiscal data
- Heuristic data repairs whose match accuracy needs human verification
- Migrations whose blast radius depends on production state we don't have visibility into from CI

## How to run

```bash
# Single migration:
php artisan migrate --path=database/migrations/manual/<filename>.php

# All manual migrations at once (rare; prefer one-at-a-time):
php artisan migrate --path=database/migrations/manual
```

After running, the migration is recorded in the `migrations` table like any other, so re-running `migrate` won't re-execute it.
