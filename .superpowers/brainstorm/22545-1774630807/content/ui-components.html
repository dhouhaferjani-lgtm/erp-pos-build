Interaction Flows

Flow 1: Item Added → Recommendations
1
Cashier scans / taps "Avène Cleanance Gel"
2
Hook debounces 800ms, calls backend
3
Backend → erp-ml (circuit breaker protected)
4
Smart prompts appear (3-5 cards, fade in)
5
Cashier taps card → product added to cart
If offline or erp-ml down → step 4 simply doesn't happen. No error shown. Cart works normally.
Flow 2: Context Question → Refined Results
1
Recommendations have skin-type-dependent options
2
Context question appears above recommendations:
What's the customer's skin type?
Normal
Oily ✓
Dry
Combination
Sensitive
3
Cashier taps "Oily" → recommendations refresh
4
If customer selected → skin type saved to profile
If customer already has skin_type on profile → pills are pre-selected, cashier can override. Selection persists for this cart.
