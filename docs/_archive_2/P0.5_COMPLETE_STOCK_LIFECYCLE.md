# P0.5: Complete Stock Lifecycle Audit & Fix

## Priority: 🔴 CRITICAL

## Status: 📊 IN PROGRESS (Updated December 2025)

## Objective

Audit and fix the **entire stock lifecycle** from A to Z. Every document that affects inventory must:
1. Correctly increment or decrement stock
2. Create proper GL entries (COGS, Inventory valuation)
3. Be inside proper transactions with pessimistic locking
4. Have audit trail via StockMovement records

---

## 🎯 CURRENT STATE (After December 2025 Audit)

### ✅ What's Working

1. **Stock Reservations System** - COMPLETE
   - `StockReservationService` fully functional with pessimistic locking
   - `SalesOrderService.confirm()` reserves stock when auto-reserve enabled
   - `DeliveryNoteService.confirm()` releases reservations
   - Event sourcing for audit trail (ReservationCreated, ReservationReleased, ReservationExpired)

2. **Weighted Average Costing** - COMPLETE
   - `WeightedAverageCostService` fully implemented
   - `recordPurchase()`, `recordSale()`, `recordReturn()` methods working
   - Proper cost updates on stock movements
   - Integration with MarginService for auto-pricing

3. **Goods Receipt** - COMPLETE
   - `GoodsReceiptService.receiveGoods()` calls WAC service
   - Stock increases on goods receipt
   - Cost updates correctly

4. **COGS Posting on Invoice** - WORKING
   - `PostCOGSOnInvoice` listener creates GL entries
   - Dr 601 (COGS) / Cr 37 (Inventory)

### ❌ Critical Gaps Found

1. **DocumentController Integration** - BROKEN
   - `DocumentController.confirm()` does NOT dispatch to domain services
   - Sales orders confirmed via API don't reserve stock
   - Delivery notes confirmed via API don't release reservations
   - **Impact**: Frontend confirmations bypass domain logic

2. **Credit Notes** - BROKEN FOR STOCK RETURNS
   - Credit notes can be created and posted
   - GL entries reverse AR and sales revenue ✅
   - **BUT** stock is NOT returned to inventory ❌
   - **AND** COGS is NOT reversed ❌
   - **Impact**: Inventory count and P&L are wrong for any business with returns

3. **Supplier Returns** - COMPLETELY MISSING
   - No `PurchaseCreditNote` document type
   - No way to return goods to suppliers
   - No AP reduction mechanism

4. **Stock Movement Records** - INCOMPLETE
   - `StockMovement` model exists but only used by reservation system
   - Not used for deliveries, receipts, or returns
   - **Impact**: Audit trail incomplete

## Stock Lifecycle Overview

### Stock INCREASES (Inbound)

| Document | Trigger | Stock Effect | GL Effect |
|----------|---------|--------------|-----------|
| **Goods Receipt Note** | Confirmation | +Stock | Debit Inventory, Credit Goods Received Not Invoiced (GRNI) |
| **Supplier Invoice** | Posting | None (already received) | Debit GRNI, Credit AP |
| **Customer Return Note** | Confirmation | +Stock (if returned) | Debit Inventory, Credit COGS (reversal) |
| **Stock Adjustment (+)** | Approval | +Stock | Debit Inventory, Credit Adjustment Account |
| **Transfer Entry Note** | Confirmation | +Stock at destination | Internal transfer (no P&L impact) |
| **Production Output** | Confirmation | +Stock (finished goods) | Debit FG Inventory, Credit WIP |

### Stock DECREASES (Outbound)

| Document | Trigger | Stock Effect | GL Effect |
|----------|---------|--------------|-----------|
| **Delivery Note** | Confirmation | -Stock | Debit COGS, Credit Inventory |
| **Supplier Return Note** | Confirmation | -Stock | Debit AP/GRNI, Credit Inventory |
| **Stock Adjustment (-)** | Approval | -Stock | Debit Loss/Expense, Credit Inventory |
| **Transfer Exit Note** | Confirmation | -Stock at source | Internal transfer (move to In-Transit) |
| **Damage/Write-off** | Approval | -Stock | Debit Loss, Credit Inventory |

### NO Stock Effect

| Document | Why No Stock Effect |
|----------|---------------------|
| **Purchase Order** | Just a commitment, no physical receipt |
| **Sales Order** | Just a commitment, may reserve stock |
| **Quote** | No commitment |
| **Invoice** | Financial only - stock moved on Delivery Note |
| **Supplier Invoice** | Financial only - stock moved on Goods Receipt |
| **Credit Note (refund only)** | Financial only - no physical return |

## Part B: Design the Unified Stock Movement Framework

### B1: Core Stock Movement Service

Create a single, authoritative service for ALL stock movements:

```php
<?php
// app/Modules/Inventory/Domain/Services/StockMovementService.php

namespace App\Modules\Inventory\Domain\Services;

use App\Modules\Inventory\Domain\StockLevel;
use App\Modules\Inventory\Domain\StockMovement;
use App\Modules\Inventory\Domain\Enums\MovementType;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Inventory\Domain\Events\StockIncreased;
use App\Modules\Inventory\Domain\Events\StockDecreased;
use App\Modules\Inventory\Exceptions\InsufficientStockException;
use Illuminate\Support\Facades\DB;

class StockMovementService
{
    public function __construct(
        private readonly CostingService $costingService,
    ) {}
    
    /**
     * Increase stock (receipts, returns, adjustments)
     */
    public function increase(StockMovementDTO $dto): StockMovement
    {
        return DB::transaction(function () use ($dto) {
            $stockLevel = $this->getOrCreateStockLevel($dto->productId, $dto->locationId);
            
            // Lock for update
            $stockLevel = StockLevel::where('id', $stockLevel->id)
                ->lockForUpdate()
                ->first();
            
            // Create movement record
            $movement = StockMovement::create([
                'product_id' => $dto->productId,
                'location_id' => $dto->locationId,
                'quantity' => $dto->quantity, // Positive
                'unit_cost' => $dto->unitCost ?? $this->costingService->getUnitCost($dto->productId),
                'movement_type' => MovementType::IN,
                'reason' => $dto->reason,
                'reference_type' => $dto->referenceType,
                'reference_id' => $dto->referenceId,
                'balance_before' => $stockLevel->quantity,
                'balance_after' => $stockLevel->quantity + $dto->quantity,
                'notes' => $dto->notes,
                'batch_number' => $dto->batchNumber,
                'expiry_date' => $dto->expiryDate,
                'created_by' => auth()->id(),
            ]);
            
            // Update stock level
            $stockLevel->increment('quantity', $dto->quantity);
            
            // Update average cost if applicable
            if ($dto->unitCost && $dto->reason !== MovementReason::TRANSFER) {
                $this->costingService->updateAverageCost($stockLevel, $dto->quantity, $dto->unitCost);
            }
            
            return $movement;
        });
    }
    
    /**
     * Decrease stock (deliveries, returns to supplier, adjustments)
     * 
     * @throws InsufficientStockException
     */
    public function decrease(StockMovementDTO $dto): StockMovement
    {
        return DB::transaction(function () use ($dto) {
            $stockLevel = StockLevel::where('product_id', $dto->productId)
                ->where('location_id', $dto->locationId)
                ->lockForUpdate()
                ->first();
            
            if (!$stockLevel) {
                throw new InsufficientStockException(
                    "No stock record for product {$dto->productId} at location {$dto->locationId}"
                );
            }
            
            // Validate sufficient stock (unless override flag)
            if (!$dto->allowNegative && $stockLevel->quantity < $dto->quantity) {
                throw new InsufficientStockException(
                    "Insufficient stock. Available: {$stockLevel->quantity}, Requested: {$dto->quantity}"
                );
            }
            
            // Get cost for COGS
            $unitCost = $dto->unitCost ?? $this->costingService->getUnitCost($dto->productId, $dto->locationId);
            
            // Create movement record
            $movement = StockMovement::create([
                'product_id' => $dto->productId,
                'location_id' => $dto->locationId,
                'quantity' => -$dto->quantity, // Negative
                'unit_cost' => $unitCost,
                'movement_type' => MovementType::OUT,
                'reason' => $dto->reason,
                'reference_type' => $dto->referenceType,
                'reference_id' => $dto->referenceId,
                'balance_before' => $stockLevel->quantity,
                'balance_after' => $stockLevel->quantity - $dto->quantity,
                'notes' => $dto->notes,
                'created_by' => auth()->id(),
            ]);
            
            // Update stock level
            $stockLevel->decrement('quantity', $dto->quantity);
            
            return $movement;
        });
    }
    
    /**
     * Transfer between locations
     */
    public function transfer(TransferDTO $dto): array
    {
        return DB::transaction(function () use ($dto) {
            // Decrease at source
            $exitMovement = $this->decrease(new StockMovementDTO(
                productId: $dto->productId,
                locationId: $dto->fromLocationId,
                quantity: $dto->quantity,
                reason: MovementReason::TRANSFER_OUT,
                referenceType: 'transfer',
                referenceId: $dto->transferId,
            ));
            
            // Increase at destination
            $entryMovement = $this->increase(new StockMovementDTO(
                productId: $dto->productId,
                locationId: $dto->toLocationId,
                quantity: $dto->quantity,
                unitCost: $exitMovement->unit_cost, // Keep same cost
                reason: MovementReason::TRANSFER_IN,
                referenceType: 'transfer',
                referenceId: $dto->transferId,
            ));
            
            return [$exitMovement, $entryMovement];
        });
    }
    
    /**
     * Adjust stock (for counts, corrections, write-offs)
     */
    public function adjust(AdjustmentDTO $dto): StockMovement
    {
        $currentQty = $this->getStockLevel($dto->productId, $dto->locationId)?->quantity ?? 0;
        $difference = $dto->newQuantity - $currentQty;
        
        if ($difference > 0) {
            return $this->increase(new StockMovementDTO(
                productId: $dto->productId,
                locationId: $dto->locationId,
                quantity: $difference,
                reason: $dto->reason,
                referenceType: 'adjustment',
                referenceId: $dto->adjustmentId,
                notes: $dto->notes,
            ));
        } else {
            return $this->decrease(new StockMovementDTO(
                productId: $dto->productId,
                locationId: $dto->locationId,
                quantity: abs($difference),
                reason: $dto->reason,
                referenceType: 'adjustment',
                referenceId: $dto->adjustmentId,
                notes: $dto->notes,
                allowNegative: true, // Adjustments can go negative
            ));
        }
    }
    
    private function getOrCreateStockLevel(string $productId, string $locationId): StockLevel
    {
        return StockLevel::firstOrCreate(
            ['product_id' => $productId, 'location_id' => $locationId],
            ['quantity' => 0, 'reserved_quantity' => 0, 'average_cost' => 0]
        );
    }
    
    private function getStockLevel(string $productId, string $locationId): ?StockLevel
    {
        return StockLevel::where('product_id', $productId)
            ->where('location_id', $locationId)
            ->first();
    }
}
```

### B2: Movement Reason Enum

```php
<?php
// app/Modules/Inventory/Domain/Enums/MovementReason.php

namespace App\Modules\Inventory\Domain\Enums;

enum MovementReason: string
{
    // Inbound
    case GOODS_RECEIPT = 'goods_receipt';
    case CUSTOMER_RETURN = 'customer_return';
    case TRANSFER_IN = 'transfer_in';
    case ADJUSTMENT_POSITIVE = 'adjustment_positive';
    case PRODUCTION_OUTPUT = 'production_output';
    case OPENING_BALANCE = 'opening_balance';
    
    // Outbound
    case DELIVERY = 'delivery';
    case SUPPLIER_RETURN = 'supplier_return';
    case TRANSFER_OUT = 'transfer_out';
    case ADJUSTMENT_NEGATIVE = 'adjustment_negative';
    case DAMAGE = 'damage';
    case EXPIRY = 'expiry';
    case WRITE_OFF = 'write_off';
    case PRODUCTION_CONSUMPTION = 'production_consumption';
    
    public function isInbound(): bool
    {
        return in_array($this, [
            self::GOODS_RECEIPT,
            self::CUSTOMER_RETURN,
            self::TRANSFER_IN,
            self::ADJUSTMENT_POSITIVE,
            self::PRODUCTION_OUTPUT,
            self::OPENING_BALANCE,
        ]);
    }
    
    public function affectsCOGS(): bool
    {
        return in_array($this, [
            self::DELIVERY,
            self::CUSTOMER_RETURN, // Reverses COGS
            self::DAMAGE,
            self::EXPIRY,
            self::WRITE_OFF,
        ]);
    }
    
    public function getGLAccountPurpose(): ?string
    {
        return match($this) {
            self::DELIVERY => 'cogs',
            self::CUSTOMER_RETURN => 'cogs', // Credit COGS
            self::DAMAGE, self::EXPIRY, self::WRITE_OFF => 'inventory_loss',
            self::ADJUSTMENT_POSITIVE => 'inventory_gain',
            self::ADJUSTMENT_NEGATIVE => 'inventory_loss',
            default => null, // Transfers don't hit P&L
        };
    }
}
```

### C1: Goods Receipt Note Listener

```php
<?php
// app/Modules/Inventory/Listeners/ProcessGoodsReceipt.php

namespace App\Modules\Inventory\Listeners;

use App\Modules\Document\Domain\Events\GoodsReceiptConfirmed;
use App\Modules\Inventory\Domain\Services\StockMovementService;
use App\Modules\Inventory\Domain\DTOs\StockMovementDTO;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Accounting\Domain\Services\GeneralLedgerService;
use Illuminate\Support\Facades\DB;

class ProcessGoodsReceipt
{
    public function __construct(
        private readonly StockMovementService $stockService,
        private readonly GeneralLedgerService $glService,
    ) {}
    
    public function handle(GoodsReceiptConfirmed $event): void
    {
        $receipt = $event->goodsReceipt;
        
        // Skip if already processed
        if ($this->alreadyProcessed($receipt)) {
            return;
        }
        
        DB::transaction(function () use ($receipt) {
            $totalValue = 0;
            
            foreach ($receipt->lines as $line) {
                if (!$this->isPhysicalProduct($line)) {
                    continue;
                }
                
                $movement = $this->stockService->increase(new StockMovementDTO(
                    productId: $line->product_id,
                    locationId: $receipt->location_id,
                    quantity: $line->quantity,
                    unitCost: $line->unit_cost,
                    reason: MovementReason::GOODS_RECEIPT,
                    referenceType: 'goods_receipt',
                    referenceId: $receipt->id,
                    batchNumber: $line->batch_number,
                    expiryDate: $line->expiry_date,
                ));
                
                $totalValue += $line->quantity * $line->unit_cost;
            }
            
            // Create GL entry: Debit Inventory, Credit GRNI
            if ($totalValue > 0) {
                $this->glService->createGoodsReceiptEntry(
                    companyId: $receipt->company_id,
                    amount: $totalValue,
                    date: $receipt->confirmed_at,
                    reference: $receipt->document_number,
                    sourceType: 'goods_receipt',
                    sourceId: $receipt->id,
                );
            }
        });
    }
    
    private function isPhysicalProduct($line): bool
    {
        return $line->product_id && $line->product?->isPhysical();
    }
    
    private function alreadyProcessed($receipt): bool
    {
        return \App\Modules\Inventory\Domain\StockMovement::where('reference_type', 'goods_receipt')
            ->where('reference_id', $receipt->id)
            ->exists();
    }
}
```

```php
namespace App\Modules\Inventory\Listeners;

use App\Modules\Document\Domain\Events\DeliveryNoteConfirmed;
use App\Modules\Inventory\Domain\Services\StockMovementService;
use App\Modules\Inventory\Domain\DTOs\StockMovementDTO;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Accounting\Domain\Services\GeneralLedgerService;
use App\Modules\Inventory\Domain\Events\StockConsumed;
use Illuminate\Support\Facades\DB;

class ProcessDeliveryNote
{
    public function __construct(
        private readonly StockMovementService $stockService,
        private readonly GeneralLedgerService $glService,
    ) {}
    
    public function handle(DeliveryNoteConfirmed $event): void
    {
        $deliveryNote = $event->deliveryNote;
        
        if ($this->alreadyProcessed($deliveryNote)) {
            return;
        }
        
        $movements = [];
        
        DB::transaction(function () use ($deliveryNote, &$movements) {
            $totalCOGS = 0;
            
            foreach ($deliveryNote->lines as $line) {
                if (!$this->isPhysicalProduct($line)) {
                    continue;
                }
                
                $movement = $this->stockService->decrease(new StockMovementDTO(
                    productId: $line->product_id,
                    locationId: $this->getLocationId($deliveryNote),
                    quantity: $line->quantity,
                    reason: MovementReason::DELIVERY,
                    referenceType: 'delivery_note',
                    referenceId: $deliveryNote->id,
                ));
                
                $movements[] = $movement;
                $totalCOGS += abs($movement->quantity) * $movement->unit_cost;
            }
            
            // Create COGS GL entry
            if ($totalCOGS > 0) {
                $this->glService->createCOGSEntry(
                    companyId: $deliveryNote->company_id,
                    amount: $totalCOGS,
                    date: $deliveryNote->confirmed_at ?? now(),
                    reference: $deliveryNote->document_number,
                    sourceType: 'delivery_note',
                    sourceId: $deliveryNote->id,
                );
            }
        });
        
        // Dispatch events after transaction
        foreach ($movements as $movement) {
            event(new StockConsumed(
                productId: $movement->product_id,
                locationId: $movement->location_id,
                quantity: abs($movement->quantity),
                sourceType: 'delivery_note',
                sourceId: $deliveryNote->id,
                unitCost: $movement->unit_cost,
            ));
        }
    }
    
    private function isPhysicalProduct($line): bool
    {
        return $line->product_id && $line->product?->isPhysical();
    }
    
    private function getLocationId($deliveryNote): string
    {
        return $deliveryNote->location_id 
            ?? $deliveryNote->company->default_location_id
            ?? throw new \DomainException("No location for delivery note");
    }
    
    private function alreadyProcessed($deliveryNote): bool
    {
        return \App\Modules\Inventory\Domain\StockMovement::where('reference_type', 'delivery_note')
            ->where('reference_id', $deliveryNote->id)
            ->exists();
    }
}
```

### C3: Customer Return Note Listener

```php
<?php
// app/Modules/Inventory/Listeners/ProcessCustomerReturn.php

namespace App\Modules\Inventory\Listeners;

use App\Modules\Document\Domain\Events\ReturnNoteConfirmed;
use App\Modules\Inventory\Domain\Services\StockMovementService;
use App\Modules\Inventory\Domain\DTOs\StockMovementDTO;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Accounting\Domain\Services\GeneralLedgerService;
use Illuminate\Support\Facades\DB;

class ProcessCustomerReturn
{
    public function __construct(
        private readonly StockMovementService $stockService,
        private readonly GeneralLedgerService $glService,
    ) {}
    
    public function handle(ReturnNoteConfirmed $event): void
    {
        $returnNote = $event->returnNote;
        
        if ($this->alreadyProcessed($returnNote)) {
            return;
        }
        
        DB::transaction(function () use ($returnNote) {
            $totalValue = 0;
            
            foreach ($returnNote->lines as $line) {
                if (!$this->isPhysicalProduct($line)) {
                    continue;
                }
                
                // Get original cost from the delivery/sale
                $originalCost = $this->getOriginalCost($line);
                
                $movement = $this->stockService->increase(new StockMovementDTO(
                    productId: $line->product_id,
                    locationId: $returnNote->location_id,
                    quantity: $line->quantity,
                    unitCost: $originalCost,
                    reason: MovementReason::CUSTOMER_RETURN,
                    referenceType: 'return_note',
                    referenceId: $returnNote->id,
                    notes: $line->return_reason,
                ));
                
                $totalValue += $line->quantity * $originalCost;
            }
            
            // Reverse COGS: Debit Inventory, Credit COGS
            if ($totalValue > 0) {
                $this->glService->reverseCOGSEntry(
                    companyId: $returnNote->company_id,
                    amount: $totalValue,
                    date: $returnNote->confirmed_at,
                    reference: $returnNote->document_number,
                    sourceType: 'return_note',
                    sourceId: $returnNote->id,
                );
            }
        });
    }
    
    private function getOriginalCost($line): float
    {
        // Try to get cost from linked delivery note line
        if ($line->source_line_id) {
            $originalMovement = \App\Modules\Inventory\Domain\StockMovement::where('reference_type', 'delivery_note')
                ->whereJsonContains('metadata->line_id', $line->source_line_id)
                ->first();
            
            if ($originalMovement) {
                return $originalMovement->unit_cost;
            }
        }
        
        // Fallback to average cost
        return app(CostingService::class)->getAverageCost($line->product_id);
    }
    
    private function isPhysicalProduct($line): bool
    {
        return $line->product_id && $line->product?->isPhysical();
    }
    
    private function alreadyProcessed($returnNote): bool
    {
        return \App\Modules\Inventory\Domain\StockMovement::where('reference_type', 'return_note')
            ->where('reference_id', $returnNote->id)
            ->exists();
    }
}
```

```php
<?php
// app/Modules/Inventory/Listeners/ProcessCreditNote.php

namespace App\Modules\Inventory\Listeners;

use App\Modules\Document\Domain\Events\CreditNotePosted;
use App\Modules\Inventory\Domain\Services\StockMovementService;
use Illuminate\Support\Facades\DB;

class ProcessCreditNote
{
    public function __construct(
        private readonly StockMovementService $stockService,
    ) {}
    
    public function handle(CreditNotePosted $event): void
    {
        $creditNote = $event->creditNote;
        
        // Check if this credit note includes a physical return
        // This could be:
        // 1. A flag: $creditNote->includes_return
        // 2. A linked return note: $creditNote->return_note_id
        // 3. A payload field: $creditNote->payload['return_type']
        
        if (!$this->includesPhysicalReturn($creditNote)) {
            // Refund only - no stock movement
            // Financial GL entries handled elsewhere
            return;
        }
        
        // If physical return is embedded in credit note (not separate document)
        // process the stock increase here
        // 
        // RECOMMENDATION: Use separate Return Note document for clarity
        // This listener then does nothing, and ProcessCustomerReturn handles it
    }
    
    private function includesPhysicalReturn($creditNote): bool
    {
        // Check for linked return note
        if ($creditNote->return_note_id) {
            return true;
        }
        
        // Check for return flag
        if ($creditNote->payload['includes_return'] ?? false) {
            return true;
        }
        
        // Check for return_type in payload
        $returnType = $creditNote->payload['return_type'] ?? 'refund_only';
        return $returnType === 'with_return';
    }
}
```
