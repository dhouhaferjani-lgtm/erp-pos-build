# P0.5: Stock Lifecycle & Reservation System (CORRECTED)

## Executive Summary

This task implements the complete stock lifecycle with a reservation system that supports internal sales orders, e-commerce carts, and marketplace orders. The implementation integrates with existing event logging, fiscal hash chain, and fraud detection infrastructure.

**Critical Principle:** All stock movements and GL entries must be atomic within the same database transaction as document confirmation. Events are dispatched AFTER commit for non-critical side effects only.

**Architecture Alignment:** This implementation follows the existing pattern used for DeliveryNoteService - integrating with DocumentController and using event listeners rather than creating new dedicated document services.

### 2.2 ReservationSource Enum

**File:** `app/Modules/Inventory/Domain/Enums/ReservationSource.php`

```php
<?php

declare(strict_types=1);

namespace App\Modules\Inventory\Domain\Enums;

use App\Modules\Company\Domain\ValueObjects\ReservationSettings;

enum ReservationSource: string
{
    case SalesOrder = 'sales_order';
    case EcommerceCart = 'ecommerce_cart';
    case MarketplaceOrder = 'marketplace_order';
    case ManualHold = 'manual_hold';
    case CustomerReturnPending = 'customer_return_pending';
    case QualityCheck = 'quality_check';
    case TransferPending = 'transfer_pending';

    /**
     * Get default expiry for this source type.
     */
    public function getDefaultExpiry(ReservationSettings $settings): ?\DateTimeInterface
    {
        return match($this) {
            self::SalesOrder => $settings->salesOrderExpiryDays > 0
                ? now()->addDays($settings->salesOrderExpiryDays)
                : null,
            self::EcommerceCart => now()->addMinutes($settings->ecommerceCartExpiryMinutes),
            self::MarketplaceOrder => now()->addHours($settings->marketplaceOrderExpiryHours),
            self::CustomerReturnPending => now()->addDays($settings->customerReturnExpiryDays),
            self::ManualHold => null, // Never expires unless explicit
            self::QualityCheck => now()->addDays(3),
            self::TransferPending => now()->addDays(1),
        };
    }

    /**
     * Whether expiration of this source type should trigger fraud alerts.
     */
    public function triggersFraudAlert(): bool
    {
        return match($this) {
            self::SalesOrder => true,
            self::MarketplaceOrder => true,
            self::ManualHold => true,
            default => false,
        };
    }

    public function label(): string
    {
        return match($this) {
            self::SalesOrder => 'Sales Order',
            self::EcommerceCart => 'E-commerce Cart',
            self::MarketplaceOrder => 'Marketplace Order',
            self::ManualHold => 'Manual Hold',
            self::CustomerReturnPending => 'Pending Customer Return',
            self::QualityCheck => 'Quality Check',
            self::TransferPending => 'Pending Transfer',
        };
    }
}
```

```php
declare(strict_types=1);

namespace App\Modules\Inventory\Domain;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class StockReservation extends Model
{
    use HasUuids;

    protected $fillable = [
        'company_id',
        'product_id',
        'location_id',
        'quantity',
        'source_type',
        'source_id',
        'source_line_id',
        'expires_at',
        'expired_at',
        'released_at',

    protected $casts = [
        'quantity' => 'decimal:4',
        'source_type' => ReservationSource::class,
        'release_reason' => ReleaseReason::class,
        'expires_at' => 'datetime',
        'expired_at' => 'datetime',
        'released_at' => 'datetime',
        'metadata' => 'array',
    ];

    // Relationships

    /** @return BelongsTo<Company, $this> */
    public function company(): BelongsTo
    {
        return $this->belongsTo(Company::class);
    }

    /** @return BelongsTo<Product, $this> */
    public function product(): BelongsTo
    {
        return $this->belongsTo(Product::class);
    }

    /** @return BelongsTo<Location, $this> */
    public function location(): BelongsTo
    {
        return $this->belongsTo(Location::class);
    }

    /** @return BelongsTo<User, $this> */
    public function createdBy(): BelongsTo
    {
        return $this->belongsTo(User::class, 'created_by');
    }

    /** @return BelongsTo<User, $this> */
    public function releasedBy(): BelongsTo
    {
        return $this->belongsTo(User::class, 'released_by');
    }

    // Scopes

    /**
     * @param \Illuminate\Database\Eloquent\Builder<StockReservation> $query
     * @return \Illuminate\Database\Eloquent\Builder<StockReservation>
     */
    public function scopeActive($query)
    {
        return $query->whereNull('released_at');
    }

    /**
     * @param \Illuminate\Database\Eloquent\Builder<StockReservation> $query
     * @return \Illuminate\Database\Eloquent\Builder<StockReservation>
     */
    public function scopeExpired($query)
    {
        return $query->active()
            ->whereNotNull('expires_at')
            ->where('expires_at', '<=', now());
    }

    /**
     * @param \Illuminate\Database\Eloquent\Builder<StockReservation> $query
     * @return \Illuminate\Database\Eloquent\Builder<StockReservation>
     */
    public function scopeForProduct($query, string $productId)
    {
        return $query->where('product_id', $productId);
    }

    /**
     * @param \Illuminate\Database\Eloquent\Builder<StockReservation> $query
     * @return \Illuminate\Database\Eloquent\Builder<StockReservation>
     */
    public function scopeForLocation($query, string $locationId)
    {
        return $query->where('location_id', $locationId);
    }

    /**
     * @param \Illuminate\Database\Eloquent\Builder<StockReservation> $query
     * @return \Illuminate\Database\Eloquent\Builder<StockReservation>
     */
    public function scopeForSource($query, ReservationSource $source, string $sourceId)
    {
        return $query->where('source_type', $source)
            ->where('source_id', $sourceId);
    }

    // Helpers

    public function isActive(): bool
    {
        return $this->released_at === null;
    }

    public function isExpired(): bool
    {
        return $this->isActive()
            && $this->expires_at !== null
            && $this->expires_at->isPast();
    }

    public function getTimeUntilExpiry(): ?int
    {
        if (!$this->isActive() || $this->expires_at === null) {
            return null;
        }

        return max(0, now()->diffInSeconds($this->expires_at, false));
    }

    public function getTotalValue(): float
    {
        return (float) $this->quantity * ($this->product?->cost_price ?? 0);
    }
}
```

**File:** `app/Modules/Inventory/Application/Services/StockReservationService.php`

```php
<?php

declare(strict_types=1);

namespace App\Modules\Inventory\Application\Services;

use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use App\Modules\Inventory\Domain\Enums\ReservationSource;
use App\Modules\Inventory\Domain\Events\ReservationCreated;
use App\Modules\Inventory\Domain\Events\ReservationExpired;
use App\Modules\Inventory\Domain\Events\ReservationReleased;
use App\Modules\Inventory\Domain\Exceptions\InsufficientStockException;
use App\Modules\Inventory\Domain\Location;
use App\Modules\Inventory\Domain\StockLevel;
use App\Modules\Inventory\Domain\StockReservation;
use App\Modules\Product\Domain\Product;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\DB;

class StockReservationService
{
    /**
     * Create a new reservation.
     * MUST be called within an existing transaction when part of order confirmation.
     *
     * @throws InsufficientStockException
     */
    public function reserve(
        Product $product,
        Location $location,
        string $quantity,
        ReservationSource $source,
        string $sourceId,
        ?string $sourceLineId = null,
        ?\DateTimeInterface $expiresAt = null,
        ?string $notes = null,
        ?string $createdById = null,
        array $metadata = [],
    ): StockReservation {
        // Get company settings for default expiry
        $company = $location->company;
        $settings = $company->getReservationSettings();

        // Calculate expiry if not provided
        $expiresAt = $expiresAt ?? $source->getDefaultExpiry($settings);

        // Lock stock level for this product/location
        $stockLevel = StockLevel::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->lockForUpdate()
            ->first();

        if (!$stockLevel) {
            throw new InsufficientStockException(
                productId: $product->id,
                locationId: $location->id,
                requested: $quantity,
                available: '0',
            );
        }

        $availableBefore = $stockLevel->getAvailableQuantity();

        if (bccomp($quantity, $availableBefore, 4) > 0) {
            throw new InsufficientStockException(
                productId: $product->id,
                locationId: $location->id,
                requested: $quantity,
                available: $availableBefore,
            );
        }

        // Create reservation
        $reservation = StockReservation::create([
            'company_id' => $company->id,
            'product_id' => $product->id,
            'location_id' => $location->id,
            'quantity' => $quantity,
            'source_type' => $source,
            'source_id' => $sourceId,
            'source_line_id' => $sourceLineId,
            'expires_at' => $expiresAt,
            'notes' => $notes,
            'metadata' => $metadata,
            'created_by' => $createdById,
        ]);

        // Update cached reserved quantity on StockLevel
        $stockLevel->reserved = bcadd((string) $stockLevel->reserved, $quantity, 4);
        $stockLevel->save();

        $availableAfter = $stockLevel->getAvailableQuantity();

        // Dispatch event AFTER transaction commits
        DB::afterCommit(function () use ($reservation, $availableBefore, $availableAfter) {
            event(new ReservationCreated(
                reservationId: $reservation->id,
                companyId: $reservation->company_id,
                productId: $reservation->product_id,
                locationId: $reservation->location_id,
                quantity: (string) $reservation->quantity,
                sourceType: $reservation->source_type->value,
                sourceId: $reservation->source_id,
                sourceLineId: $reservation->source_line_id,
                expiresAt: $reservation->expires_at?->toIso8601String(),
                availableBefore: $availableBefore,
                availableAfter: $availableAfter,
                createdBy: $reservation->created_by,
            ));
        });

        return $reservation;
    }

    /**
     * Release a specific reservation.
     * MUST be called within an existing transaction when part of delivery confirmation.
     */
    public function release(
        StockReservation $reservation,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): void {
        if (!$reservation->isActive()) {
            return; // Already released
        }

        // Lock the reservation
        /** @var StockReservation|null $reservation */
        $reservation = StockReservation::where('id', $reservation->id)
            ->lockForUpdate()
            ->first();

        if (!$reservation || !$reservation->isActive()) {
            return;
        }

        // Update reservation
        $reservation->released_at = now();
        $reservation->released_by = $releasedById;
        $reservation->release_reason = $reason;

        if ($reason === ReleaseReason::Expired) {
            $reservation->expired_at = now();
        }

        $reservation->save();

        // Update cached reserved quantity on StockLevel
        $stockLevel = StockLevel::where('product_id', $reservation->product_id)
            ->where('location_id', $reservation->location_id)
            ->lockForUpdate()
            ->first();

        if ($stockLevel) {
            $newReserved = bcsub((string) $stockLevel->reserved, (string) $reservation->quantity, 4);
            $stockLevel->reserved = bcmax('0', $newReserved);
            $stockLevel->save();
        }

        // Dispatch events AFTER transaction commits
        DB::afterCommit(function () use ($reservation, $reason, $releasedById) {
            event(new ReservationReleased(
                reservationId: $reservation->id,
                companyId: $reservation->company_id,
                productId: $reservation->product_id,
                locationId: $reservation->location_id,
                quantity: (string) $reservation->quantity,
                sourceType: $reservation->source_type->value,
                sourceId: $reservation->source_id,
                releaseReason: $reason->value,
                releasedBy: $releasedById,
            ));

            // If expired and triggers fraud alert, queue that too
            if ($reason === ReleaseReason::Expired && $reservation->source_type->triggersFraudAlert()) {
                event(new ReservationExpired(
                    reservationId: $reservation->id,
                    companyId: $reservation->company_id,
                    productId: $reservation->product_id,
                    locationId: $reservation->location_id,
                    quantity: (string) $reservation->quantity,
                    reservedValue: (string) $reservation->getTotalValue(),
                    sourceType: $reservation->source_type->value,
                    sourceId: $reservation->source_id,
                    triggersFraudAlert: true,
                    createdBy: $reservation->created_by,
                ));
            }
        });
    }

    /**
     * Release all reservations for a source (e.g., when order is delivered or cancelled).
     * Returns the total quantity released.
     */
    public function releaseBySource(
        ReservationSource $source,
        string $sourceId,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): string {
        $reservations = StockReservation::forSource($source, $sourceId)
            ->active()
            ->get();

        $totalReleased = '0';

        foreach ($reservations as $reservation) {
            $this->release($reservation, $reason, $releasedById);
            $totalReleased = bcadd($totalReleased, (string) $reservation->quantity, 4);
        }

        return $totalReleased;
    }

    /**
     * Release reservation for a specific source line.
     */
    public function releaseBySourceLine(
        ReservationSource $source,
        string $sourceId,
        string $sourceLineId,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): ?StockReservation {
        $reservation = StockReservation::forSource($source, $sourceId)
            ->where('source_line_id', $sourceLineId)
            ->active()
            ->first();

        if ($reservation) {
            $this->release($reservation, $reason, $releasedById);
        }

        return $reservation;
    }

    /**
     * Convert a reservation from one source to another (e.g., cart → order).
     */
    public function convert(
        StockReservation $reservation,
        ReservationSource $newSource,
        string $newSourceId,
        ?string $newSourceLineId = null,
        ?\DateTimeInterface $newExpiresAt = null,
    ): StockReservation {
        if (!$reservation->isActive()) {
            throw new \DomainException('Cannot convert a released reservation');
        }

        // Get new expiry from company settings if not provided
        $company = $reservation->company;
        $settings = $company->getReservationSettings();
        $newExpiresAt = $newExpiresAt ?? $newSource->getDefaultExpiry($settings);

        // Update reservation in place
        $reservation->source_type = $newSource;
        $reservation->source_id = $newSourceId;
        $reservation->source_line_id = $newSourceLineId;
        $reservation->expires_at = $newExpiresAt;
        $reservation->metadata = array_merge($reservation->metadata ?? [], [
            'converted_from' => [
                'source_type' => $reservation->getOriginal('source_type'),
                'source_id' => $reservation->getOriginal('source_id'),
                'converted_at' => now()->toIso8601String(),
            ],
        ]);
        $reservation->save();

        return $reservation;
    }

    /**
     * Process expired reservations. Called by scheduler.
     * Returns count of expired reservations.
     */
    public function expireReservations(): int
    {
        $expired = StockReservation::expired()->get();
        $count = 0;

        foreach ($expired as $reservation) {
            DB::transaction(function () use ($reservation) {
                $this->release($reservation, ReleaseReason::Expired);
            });

            $count++;
        }

        return $count;
    }

    /**
     * Get reservation breakdown for a product/location (for UI display).
     *
     * @return Collection<int, array<string, mixed>>
     */
    public function getBreakdown(
        Product $product,
        Location $location,
    ): Collection {
        return StockReservation::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->active()
            ->with(['createdBy'])
            ->orderBy('created_at')
            ->get()
            ->map(fn ($r) => [
                'id' => $r->id,
                'quantity' => $r->quantity,
                'source_type' => $r->source_type->value,
                'source_label' => $r->source_type->label(),
                'source_id' => $r->source_id,
                'expires_at' => $r->expires_at?->toIso8601String(),
                'time_until_expiry_seconds' => $r->getTimeUntilExpiry(),
                'created_at' => $r->created_at->toIso8601String(),
                'created_by' => $r->createdBy?->name,
                'notes' => $r->notes,
            ]);
    }

    /**
     * Check if a product has sufficient available quantity.
     */
    public function hasAvailableStock(
        Product $product,
        Location $location,
        string $quantity,
    ): bool {
        $stockLevel = StockLevel::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->first();

        if (!$stockLevel) {
            return false;
        }

        return bccomp($stockLevel->getAvailableQuantity(), $quantity, 4) >= 0;
    }
}

    {
        return bccomp($a, $b, $scale) >= 0 ? $a : $b;
```

```php
<?php

declare(strict_types=1);

namespace App\Modules\Document\Domain\Services;

use App\Modules\Accounting\Application\Services\GeneralLedgerService;
use App\Modules\Compliance\Services\FiscalHashService;
use App\Modules\Document\Domain\Document;
use App\Modules\Document\Domain\Enums\DocumentStatus;
use App\Modules\Document\Domain\Enums\DocumentType;
use App\Modules\Document\Domain\Enums\FiscalCategory;
use App\Modules\Document\Domain\Enums\FiscalStatus;
use App\Modules\Document\Domain\Events\DeliveryNoteConfirmed;
use App\Modules\Inventory\Application\Services\StockReservationService;
use App\Modules\Inventory\Application\Services\WeightedAverageCostService;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use App\Modules\Inventory\Domain\Enums\ReservationSource;
use Illuminate\Support\Facades\DB;

/**
 * Service responsible for delivery note operations with fiscal hash chain compliance.
 *
 * CRITICAL: This service now handles COMPLETE delivery flow:
 * 1. Release stock reservations (if any)
 * 2. Decrement physical stock
 * 3. Record stock movements
 * 4. Create COGS GL entry
 * 5. Apply fiscal hash
 * 6. Update status
 *
 * ALL operations are ATOMIC within a single transaction.
 */
final class DeliveryNoteService
{
    public function __construct(
        private readonly FiscalHashService $hashService,
        private readonly StockReservationService $reservationService,
        private readonly WeightedAverageCostService $wacService,
        private readonly GeneralLedgerService $glService,
    ) {}

    /**
     * Confirm a delivery note, adding it to the fiscal hash chain.
     *
     * This performs ALL of the following in a SINGLE transaction:
     * - Release reservations (if linked to sales order)
     * - Decrement physical stock
     * - Create stock movements
     * - Create COGS GL entry
     * - Apply fiscal hash
     * - Update status
     *
     * @throws \DomainException If delivery note cannot be confirmed
     */
    public function confirm(Document $deliveryNote, ?string $confirmedById = null): Document
    {
        if ($deliveryNote->type !== DocumentType::DeliveryNote) {
            throw new \DomainException(
                'Only delivery notes can be confirmed with this service.'
            );
        }

        if (!$deliveryNote->isDraft()) {
            throw new \DomainException(
                'Only draft delivery notes can be confirmed. Current status: '.$deliveryNote->status->value
            );
        }

        return DB::transaction(function () use ($deliveryNote, $confirmedById): Document {
            // Reload with lock and relationships
            /** @var Document $deliveryNote */
            $deliveryNote = Document::where('id', $deliveryNote->id)
                ->with(['lines.product', 'location', 'salesOrder'])
                ->lockForUpdate()
                ->firstOrFail();

            if (!$deliveryNote->isDraft()) {
                throw new \DomainException('Delivery note was already confirmed');
            }

            $totalCOGS = '0';

            // Process each line
            foreach ($deliveryNote->lines as $line) {
                // Skip non-physical products
                if (!$line->product_id || !$line->product?->isPhysical()) {
                    continue;
                }

                // 1. Release reservation if this DN is linked to a Sales Order
                if ($deliveryNote->sales_order_id && $line->sales_order_line_id) {
                    $this->reservationService->releaseBySourceLine(
                        source: ReservationSource::SalesOrder,
                        sourceId: $deliveryNote->sales_order_id,
                        sourceLineId: $line->sales_order_line_id,
                        reason: ReleaseReason::Delivered,
                        releasedById: $confirmedById,
                    );
                }

                // 2. Decrement stock and capture COGS
                // recordSale already uses lockForUpdate internally
                $movement = $this->wacService->recordSale(
                    product: $line->product,
                    location: $deliveryNote->location,
                    quantity: (float) $line->quantity,
                    reference: "DN:{$deliveryNote->document_number}:L{$line->id}",
                );

                // Update movement with granular tracking
                $movement->update([
                    'reason' => MovementReason::Delivery->value,
                    'reference_type' => Document::class,
                    'reference_id' => $deliveryNote->id,
                ]);

                $totalCOGS = bcadd($totalCOGS, (string) $movement->total_cost, 2);
            }

            // 3. Create COGS GL entry (inside transaction!)
            if (bccomp($totalCOGS, '0', 2) > 0) {
                $this->glService->createCOGSEntry(
                    companyId: $deliveryNote->company_id,
                    amount: (float) $totalCOGS,
                    date: $deliveryNote->document_date ?? now(),
                    reference: $deliveryNote->document_number,
                    sourceType: 'delivery_note',
                    sourceId: $deliveryNote->id,
                    description: "COGS for delivery {$deliveryNote->document_number}",
                );
            }

            // 4. Apply fiscal hash chain
            $this->confirmWithFiscalChain($deliveryNote, $confirmedById);

            // 5. Store COGS on document for reference
            $payload = $deliveryNote->payload ?? [];
            $payload['cogs_amount'] = $totalCOGS;
            $deliveryNote->payload = $payload;
            $deliveryNote->save();

            return $deliveryNote->fresh(['lines']);
        });

        // Event dispatched automatically by confirmWithFiscalChain via DB::afterCommit
    }

    /**
     * Confirm a delivery note with full fiscal hash chain compliance.
     */
    private function confirmWithFiscalChain(Document $deliveryNote, ?string $confirmedById): void
    {
        // Acquire lock and get previous delivery note in chain
        $previousDoc = Document::where('company_id', $deliveryNote->company_id)
            ->where('type', DocumentType::DeliveryNote)
            ->where('status', DocumentStatus::Confirmed)
            ->whereNotNull('fiscal_hash')
            ->orderByDesc('chain_sequence')
            ->lockForUpdate()
            ->first();

        // For genesis document, use company's unique seed
        $previousHash = $previousDoc?->fiscal_hash;
        $genesisSeed = $previousHash === null ? $this->getCompanyGenesisSeed($deliveryNote) : null;

        $chainSequence = ($previousDoc?->chain_sequence ?? 0) + 1;
        $confirmedAt = now();

        // Calculate fiscal hash using the compliance service
        $input = $this->hashService->serializeForHashing([
            'document_number' => $deliveryNote->document_number,
            'posted_at' => $confirmedAt->toDateString(),
            'total' => $deliveryNote->total ?? '0.00',
            'currency' => $deliveryNote->currency,
        ]);

        $fiscalHash = $this->hashService->calculateHash($input, $previousHash, $genesisSeed);

        // Update delivery note with fiscal chain data and seal it
        $deliveryNote->update([
            'status' => DocumentStatus::Confirmed,
            'fiscal_category' => FiscalCategory::DeliveryNote,
            'fiscal_status' => FiscalStatus::Sealed,
            'fiscal_hash' => $fiscalHash,
            'previous_hash' => $previousHash,
            'chain_sequence' => $chainSequence,
            'confirmed_at' => $confirmedAt,
            'confirmed_by' => $confirmedById,
        ]);

        // Dispatch the fiscal event for audit log AFTER commit
        DB::afterCommit(function () use ($deliveryNote, $confirmedAt) {
            $this->dispatchConfirmedEvent($deliveryNote, $confirmedAt->toIso8601String());
        });
    }

    /**
     * Dispatch the DeliveryNoteConfirmed event for fiscal audit trail.
     */
    private function dispatchConfirmedEvent(Document $deliveryNote, string $confirmedAt): void
    {
        event(new DeliveryNoteConfirmed(
            deliveryNoteId: $deliveryNote->id,
            tenantId: $deliveryNote->tenant_id,
            companyId: $deliveryNote->company_id,
            documentNumber: $deliveryNote->document_number,
            partnerId: $deliveryNote->partner_id,
            total: $deliveryNote->total ?? '0.00',
            currency: $deliveryNote->currency,
            fiscalHash: $deliveryNote->fiscal_hash ?? '',
            chainSequence: $deliveryNote->chain_sequence ?? 0,
            confirmedAt: $confirmedAt,
        ));
    }

    /**
     * Get the company's unique genesis seed for hash chain initialization.
     *
     * @throws \RuntimeException If company has no genesis seed
     */
    private function getCompanyGenesisSeed(Document $deliveryNote): string
    {
        $company = $deliveryNote->company;

        if ($company === null) {
            throw new \RuntimeException(
                'Delivery note must have an associated company for fiscal chain'
            );
        }

        if ($company->fiscal_chain_seed === null) {
            throw new \RuntimeException(
                'Company is missing fiscal_chain_seed. Run migration to generate seeds.'
            );
        }

        return $company->fiscal_chain_seed;
```

```php
public function confirm(Request $request, DocumentType $type, string $document): JsonResponse
{
    /** @var User $user */
    $user = $request->user();
    $companyId = $this->companyContext->requireCompanyId();

    // Initial existence check (without lock - for fast 404 response)
    $exists = Document::forCompany($companyId)
        ->ofType($type)
        ->where('id', $document)
        ->exists();

    if (! $exists) {
        return response()->json([
            'error' => [
                'code' => 'NOT_FOUND',
                'message' => 'Document not found',
            ],
        ], 404);
    }

    try {
        $documentModel = DB::transaction(function () use ($companyId, $type, $document, $user): Document {
            // Re-fetch with pessimistic lock inside transaction
            $lockedDocument = Document::forCompany($companyId)
                ->ofType($type)
                ->lockForUpdate()
                ->find($document);

            if ($lockedDocument === null) {
                throw new \DomainException('Document not found');
            }

            // Check status inside the lock - this is the idempotency check
            if (! $lockedDocument->isDraft()) {
                // Already confirmed - return silently (idempotent)
                if ($lockedDocument->status === DocumentStatus::Confirmed) {
                    return $lockedDocument;
                }
                throw new \DomainException('Only draft documents can be confirmed');
            }

            // Update document status and confirmation tracking
            $lockedDocument->update([
                'status' => DocumentStatus::Confirmed,
                'confirmed_at' => now(),
                'confirmed_by' => $user->id,
            ]);

            return $lockedDocument;
        });

        // Dispatch appropriate event AFTER transaction commits
        DB::afterCommit(function () use ($documentModel, $type, $user) {
            match ($type) {
                DocumentType::SalesOrder => event(new \App\Modules\Document\Domain\Events\SalesOrderConfirmed(
                    salesOrderId: $documentModel->id,
                    tenantId: $documentModel->tenant_id,
                    companyId: $documentModel->company_id,
                    documentNumber: $documentModel->document_number,
                    partnerId: $documentModel->partner_id,
                    locationId: $documentModel->location_id,
                    total: $documentModel->total ?? '0.00',
                    currency: $documentModel->currency,
                    confirmedBy: $user->id,
                    confirmedAt: $documentModel->confirmed_at->toIso8601String(),
                )),
                // Other document types can have their own events...
                default => null,
            };
        });

        return response()->json([
            'data' => new DocumentResource($documentModel),
        ]);
    } catch (\DomainException $e) {
        return response()->json([
            'error' => [
                'code' => 'INVALID_OPERATION',
                'message' => $e->getMessage(),
            ],
        ], 422);
    }
}
```

```php
     * GET /api/v1/inventory/reservations/breakdown

     */
    public function breakdown(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'product_id' => 'required|uuid|exists:products,id',
            'location_id' => 'required|uuid|exists:locations,id',

            'data' => $breakdown,
            'meta' => [
                'product_id' => $product->id,
                'location_id' => $location->id,
                'total_reserved' => $breakdown->sum('quantity'),
            ],
        ]);
    }
```

## Architecture Notes

### Transaction Boundaries

```
┌─────────────────────────────────────────────────────────────────┐
│ INSIDE TRANSACTION (Atomic - All or Nothing)                    │
├─────────────────────────────────────────────────────────────────┤
│ • Stock reservation/release                                     │
│ • Stock quantity changes                                        │
│ • Stock movement records                                        │
│ • GL entries (COGS, Inventory)                                  │
│ • Fiscal hash generation                                        │
│ • Document status update                                        │
└─────────────────────────────────────────────────────────────────┘
                              │
                         COMMIT
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│ AFTER TRANSACTION (Side Effects - Can Fail Safely)              │
├─────────────────────────────────────────────────────────────────┤
│ • Event dispatching (via DB::afterCommit)                       │
│ • Notifications                                                 │
│ • Webhooks                                                      │
│ • Analytics/logging                                             │
│ • Fraud detection alerts                                        │
└─────────────────────────────────────────────────────────────────┘
```

### Event Flow Pattern

```
DocumentController::confirm(SalesOrder)
  └─> DB::transaction
       └─> Update document status
       └─> Add confirmed_by, confirmed_at
  └─> DB::afterCommit
       └─> Dispatch SalesOrderConfirmed event
            └─> ReserveStockOnSalesOrder listener
                 └─> DB::transaction (new)
                      └─> Create reservations
                      └─> Update StockLevel.reserved
                 └─> DB::afterCommit
                      └─> Dispatch ReservationCreated events
```
