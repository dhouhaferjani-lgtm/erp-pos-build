# P0.5: Stock Lifecycle & Reservation System

## Executive Summary

This task implements the complete stock lifecycle with a reservation system that supports internal sales orders, e-commerce carts, and marketplace orders. The implementation must integrate with Otospex's existing event logging and fraud detection infrastructure.

**Critical Principle:** All stock movements and GL entries must be atomic within the same database transaction as document confirmation. Events are dispatched AFTER commit for non-critical side effects only.

```php
declare(strict_types=1);

namespace App\Modules\Inventory\Domain\Enums;

enum ReservationSource: string
{
    case SALES_ORDER = 'sales_order';
    case ECOMMERCE_CART = 'ecommerce_cart';
    case MARKETPLACE_ORDER = 'marketplace_order';
    case MANUAL_HOLD = 'manual_hold';
    case CUSTOMER_RETURN_PENDING = 'customer_return_pending';
    case QUALITY_CHECK = 'quality_check';
    case TRANSFER_PENDING = 'transfer_pending';
    
    /**
     * Get default expiry for this source type
     */
    public function getDefaultExpiry(array $companySettings): ?\DateTimeInterface
    {
        return match($this) {
            self::SALES_ORDER => $companySettings['sales_order_expiry_days'] 
                ? now()->addDays($companySettings['sales_order_expiry_days']) 
                : null,
            self::ECOMMERCE_CART => now()->addMinutes(
                $companySettings['ecommerce_cart_expiry_minutes'] ?? 15
            ),
            self::MARKETPLACE_ORDER => now()->addHours(
                $companySettings['marketplace_order_expiry_hours'] ?? 24
            ),
            self::CUSTOMER_RETURN_PENDING => now()->addDays(
                $companySettings['customer_return_expiry_days'] ?? 14
            ),
            self::MANUAL_HOLD => null, // Never expires unless explicit
            self::QUALITY_CHECK => now()->addDays(3),
            self::TRANSFER_PENDING => now()->addDays(1),
        };
    }
    
    /**
     * Whether expiration of this source type should trigger fraud alerts
     */
    public function triggersFraudAlert(): bool
    {
        return match($this) {
            self::SALES_ORDER => true,
            self::MARKETPLACE_ORDER => true,
            self::MANUAL_HOLD => true,
            default => false,
        };
    }
    
    public function label(): string
    {
        return match($this) {
            self::SALES_ORDER => 'Sales Order',
            self::ECOMMERCE_CART => 'E-commerce Cart',
            self::MARKETPLACE_ORDER => 'Marketplace Order',
            self::MANUAL_HOLD => 'Manual Hold',
            self::CUSTOMER_RETURN_PENDING => 'Pending Customer Return',
            self::QUALITY_CHECK => 'Quality Check',
```

```php
declare(strict_types=1);

namespace App\Modules\Inventory\Domain;

use App\Modules\Inventory\Domain\Enums\ReservationSource;
use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use Illuminate\Database\Eloquent\Concerns\HasUuids;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;

class StockReservation extends Model
{
    use HasUuids;
    
    protected $fillable = [
        'company_id',
        'product_id',
        'location_id',
        'quantity',
        'source_type',
        'source_id',
        'source_line_id',
        'expires_at',
        'expired_at',
        'released_at',
        'released_by',
        'release_reason',
        'priority',
        'notes',
        'metadata',
        'created_by',
    ];
    
    protected $casts = [
        'quantity' => 'decimal:4',
        'source_type' => ReservationSource::class,
        'release_reason' => ReleaseReason::class,
        'expires_at' => 'datetime',
        'expired_at' => 'datetime',
        'released_at' => 'datetime',
        'metadata' => 'array',
    ];
    
    // Relationships
    public function company(): BelongsTo
    {
        return $this->belongsTo(\App\Modules\Company\Domain\Company::class);
    }
    
    public function product(): BelongsTo
    {
        return $this->belongsTo(\App\Modules\Catalog\Domain\Product::class);
    }
    
    public function location(): BelongsTo
    {
        return $this->belongsTo(\App\Modules\Inventory\Domain\Location::class);
    }
    
    public function createdBy(): BelongsTo
    {
        return $this->belongsTo(\App\Modules\Identity\Domain\User::class, 'created_by');
    }
    
    public function releasedBy(): BelongsTo
    {
        return $this->belongsTo(\App\Modules\Identity\Domain\User::class, 'released_by');
    }
    
    // Scopes
    public function scopeActive($query)
    {
        return $query->whereNull('released_at');
    }
    
    public function scopeExpired($query)
    {
        return $query->active()
            ->whereNotNull('expires_at')
            ->where('expires_at', '<=', now());
    }
    
    public function scopeForProduct($query, string $productId)
    {
        return $query->where('product_id', $productId);
    }
    
    public function scopeForLocation($query, string $locationId)
    {
        return $query->where('location_id', $locationId);
    }
    
    public function scopeForSource($query, ReservationSource $source, string $sourceId)
    {
        return $query->where('source_type', $source)
            ->where('source_id', $sourceId);
    }
    
    // Helpers
    public function isActive(): bool
    {
        return $this->released_at === null;
    }
    
    public function isExpired(): bool
    {
        return $this->isActive() 
            && $this->expires_at !== null 
            && $this->expires_at->isPast();
    }
    
    public function getTimeUntilExpiry(): ?int
    {
        if (!$this->isActive() || $this->expires_at === null) {
            return null;
        }
        
        return max(0, now()->diffInSeconds($this->expires_at, false));
    }
    
    public function getTotalValue(): float
    {
        return (float) $this->quantity * ($this->product?->cost_price ?? 0);
    }
}
```

## Phase 5: Stock Reservation Service

**File:** `app/Modules/Inventory/Application/Services/StockReservationService.php`

```php
<?php

declare(strict_types=1);

namespace App\Modules\Inventory\Application\Services;

use App\Modules\Catalog\Domain\Product;
use App\Modules\Company\Domain\Company;
use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use App\Modules\Inventory\Domain\Enums\ReservationSource;
use App\Modules\Inventory\Domain\Events\ReservationCreated;
use App\Modules\Inventory\Domain\Events\ReservationExpired;
use App\Modules\Inventory\Domain\Events\ReservationReleased;
use App\Modules\Inventory\Domain\Location;
use App\Modules\Inventory\Domain\StockLevel;
use App\Modules\Inventory\Domain\StockReservation;
use App\Modules\Inventory\Domain\Exceptions\InsufficientStockException;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\DB;

class StockReservationService
{
    /**
     * Create a new reservation.
     * MUST be called within an existing transaction when part of order confirmation.
     * 
     * @throws InsufficientStockException
     */
    public function reserve(
        Product $product,
        Location $location,
        float $quantity,
        ReservationSource $source,
        string $sourceId,
        ?string $sourceLineId = null,
        ?\DateTimeInterface $expiresAt = null,
        ?string $notes = null,
        ?string $createdById = null,
        array $metadata = [],
    ): StockReservation {
        // Get company settings for default expiry
        $company = $location->company;
        $settings = $company->reservation_settings ?? [];
        
        // Calculate expiry if not provided
        $expiresAt = $expiresAt ?? $source->getDefaultExpiry($settings);
        
        // Lock stock level for this product/location
        $stockLevel = StockLevel::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->lockForUpdate()
            ->first();
        
        if (!$stockLevel) {
            throw new InsufficientStockException(
                product: $product,
                location: $location,
                requested: $quantity,
                available: 0,
            );
        }
        
        $available = $stockLevel->getAvailableQuantity();
        
        if ($available < $quantity) {
            throw new InsufficientStockException(
                product: $product,
                location: $location,
                requested: $quantity,
                available: $available,
            );
        }
        
        // Create reservation
        $reservation = StockReservation::create([
            'company_id' => $company->id,
            'product_id' => $product->id,
            'location_id' => $location->id,
            'quantity' => $quantity,
            'source_type' => $source,
            'source_id' => $sourceId,
            'source_line_id' => $sourceLineId,
            'expires_at' => $expiresAt,
            'notes' => $notes,
            'metadata' => $metadata,
            'created_by' => $createdById,
        ]);
        
        // Update cached reserved quantity on StockLevel
        $stockLevel->reserved = (float) $stockLevel->reserved + $quantity;
        $stockLevel->save();
        
        // Event will be dispatched after transaction commits
        // Store for post-commit dispatch
        $this->pendingEvents[] = new ReservationCreated($reservation, [
            'available_before' => $available,
            'available_after' => $available - $quantity,
        ]);
        
        return $reservation;
    }
    
    /**
     * Release a specific reservation.
     * MUST be called within an existing transaction when part of delivery confirmation.
     */
    public function release(
        StockReservation $reservation,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): void {
        if (!$reservation->isActive()) {
            return; // Already released
        }
        
        // Lock the reservation
        $reservation = StockReservation::where('id', $reservation->id)
            ->lockForUpdate()
            ->first();
        
        if (!$reservation->isActive()) {
            return;
        }
        
        // Update reservation
        $reservation->released_at = now();
        $reservation->released_by = $releasedById;
        $reservation->release_reason = $reason;
        
        if ($reason === ReleaseReason::EXPIRED) {
            $reservation->expired_at = now();
        }
        
        $reservation->save();
        
        // Update cached reserved quantity on StockLevel
        $stockLevel = StockLevel::where('product_id', $reservation->product_id)
            ->where('location_id', $reservation->location_id)
            ->lockForUpdate()
            ->first();
        
        if ($stockLevel) {
            $stockLevel->reserved = max(0, (float) $stockLevel->reserved - (float) $reservation->quantity);
            $stockLevel->save();
        }
        
        // Store event for post-commit dispatch
        $this->pendingEvents[] = new ReservationReleased(
            $reservation, 
            $reason, 
            $releasedById
        );
        
        // If expired and triggers fraud alert, queue that too
        if ($reason === ReleaseReason::EXPIRED && $reservation->source_type->triggersFraudAlert()) {
            $this->pendingEvents[] = new ReservationExpired(
                $reservation,
                $reservation->getTotalValue(),
            );
        }
    }
    
    /**
     * Release all reservations for a source (e.g., when order is delivered or cancelled).
     * Returns the total quantity released.
     */
    public function releaseBySource(
        ReservationSource $source,
        string $sourceId,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): float {
        $reservations = StockReservation::forSource($source, $sourceId)
            ->active()
            ->get();
        
        $totalReleased = 0;
        
        foreach ($reservations as $reservation) {
            $this->release($reservation, $reason, $releasedById);
            $totalReleased += (float) $reservation->quantity;
        }
        
        return $totalReleased;
    }
    
    /**
     * Release reservation for a specific source line.
     */
    public function releaseBySourceLine(
        ReservationSource $source,
        string $sourceId,
        string $sourceLineId,
        ReleaseReason $reason,
        ?string $releasedById = null,
    ): ?StockReservation {
        $reservation = StockReservation::forSource($source, $sourceId)
            ->where('source_line_id', $sourceLineId)
            ->active()
            ->first();
        
        if ($reservation) {
            $this->release($reservation, $reason, $releasedById);
        }
        
        return $reservation;
    }
    
    /**
     * Convert a reservation from one source to another (e.g., cart → order).
     */
    public function convert(
        StockReservation $reservation,
        ReservationSource $newSource,
        string $newSourceId,
        ?string $newSourceLineId = null,
        ?\DateTimeInterface $newExpiresAt = null,
    ): StockReservation {
        if (!$reservation->isActive()) {
            throw new \DomainException('Cannot convert a released reservation');
        }
        
        // Get new expiry from company settings if not provided
        $company = $reservation->company;
        $settings = $company->reservation_settings ?? [];
        $newExpiresAt = $newExpiresAt ?? $newSource->getDefaultExpiry($settings);
        
        // Update reservation in place
        $reservation->source_type = $newSource;
        $reservation->source_id = $newSourceId;
        $reservation->source_line_id = $newSourceLineId;
        $reservation->expires_at = $newExpiresAt;
        $reservation->metadata = array_merge($reservation->metadata ?? [], [
            'converted_from' => [
                'source_type' => $reservation->getOriginal('source_type'),
                'source_id' => $reservation->getOriginal('source_id'),
                'converted_at' => now()->toIso8601String(),
            ],
        ]);
        $reservation->save();
        
        return $reservation;
    }
    
    /**
     * Process expired reservations. Called by scheduler.
     * Returns count of expired reservations.
     */
    public function expireReservations(): int
    {
        $expired = StockReservation::expired()->get();
        $count = 0;
        
        foreach ($expired as $reservation) {
            DB::transaction(function () use ($reservation) {
                $this->release($reservation, ReleaseReason::EXPIRED);
            });
            
            // Dispatch events after each transaction
            $this->dispatchPendingEvents();
            $count++;
        }
        
        return $count;
    }
    
    /**
     * Get reservation breakdown for a product/location (for UI display).
     */
    public function getBreakdown(
        Product $product,
        Location $location,
    ): Collection {
        return StockReservation::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->active()
            ->with(['createdBy'])
            ->orderBy('created_at')
            ->get()
            ->map(fn ($r) => [
                'id' => $r->id,
                'quantity' => $r->quantity,
                'source_type' => $r->source_type->value,
                'source_label' => $r->source_type->label(),
                'source_id' => $r->source_id,
                'expires_at' => $r->expires_at?->toIso8601String(),
                'time_until_expiry_seconds' => $r->getTimeUntilExpiry(),
                'created_at' => $r->created_at->toIso8601String(),
                'created_by' => $r->createdBy?->name,
                'notes' => $r->notes,
            ]);
    }
    
    /**
     * Check if a product has sufficient available quantity.
     */
    public function hasAvailableStock(
        Product $product,
        Location $location,
        float $quantity,
    ): bool {
        $stockLevel = StockLevel::where('product_id', $product->id)
            ->where('location_id', $location->id)
            ->first();
        
        if (!$stockLevel) {
            return false;
        }
        
        return $stockLevel->getAvailableQuantity() >= $quantity;
    }
    
    // Event management
    private array $pendingEvents = [];
    
    public function dispatchPendingEvents(): void
    {
        foreach ($this->pendingEvents as $event) {
            event($event);
        }
        $this->pendingEvents = [];
    }
    
    public function clearPendingEvents(): void
    {
        $this->pendingEvents = [];
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Modules\Document\Domain\Services;

use App\Modules\Document\Domain\Document;
use App\Modules\Document\Domain\Enums\DocumentStatus;
use App\Modules\Document\Domain\Events\SalesOrderConfirmed;
use App\Modules\Inventory\Application\Services\StockReservationService;

use App\Modules\Inventory\Domain\Exceptions\InsufficientStockException;
use Illuminate\Support\Facades\DB;

class SalesOrderService
{
    public function __construct(
        private readonly StockReservationService $reservationService,
        private readonly FiscalHashService $fiscalHashService,
    ) {}
    
    /**
     * Confirm a sales order.
     * This reserves stock for all physical product lines.
     * 
     * @throws InsufficientStockException
     */
    public function confirm(Document $salesOrder, ?string $confirmedById = null): Document
    {
        if ($salesOrder->status !== DocumentStatus::DRAFT) {
            throw new \DomainException('Only draft sales orders can be confirmed');
        }
        
        $company = $salesOrder->company;
        $settings = $company->reservation_settings ?? [];
        
        // Skip reservation if disabled for this company
        $autoReserve = $settings['auto_reserve_on_sales_order'] ?? true;
        
        $salesOrder = DB::transaction(function () use ($salesOrder, $confirmedById, $autoReserve) {
            // Lock the document
            $salesOrder = Document::where('id', $salesOrder->id)
                ->lockForUpdate()
                ->first();
            
            if ($salesOrder->status !== DocumentStatus::DRAFT) {
                throw new \DomainException('Order was already confirmed');
            }
            
            // Reserve stock for each physical product line
            if ($autoReserve) {
                foreach ($salesOrder->lines as $line) {
                    // Skip non-physical products (services, etc.)
                    if (!$line->product_id || !$line->product?->isPhysical()) {
                        continue;
                    }
                    
                    // This will throw InsufficientStockException if not available
                    $this->reservationService->reserve(
                        product: $line->product,
                        location: $salesOrder->location,
                        quantity: (float) $line->quantity,
                        source: ReservationSource::SALES_ORDER,
                        sourceId: $salesOrder->id,
                        sourceLineId: $line->id,
                        createdById: $confirmedById,
                        metadata: [
                            'document_number' => $salesOrder->document_number,
                            'customer_id' => $salesOrder->customer_id,
                            'line_number' => $line->line_number,
                        ],
                    );
                }
            }
            
            // Apply fiscal hash if required
            // Note: Some countries may not require hash on SO, check your requirements
            // $this->fiscalHashService->applyHash($salesOrder);
            
            // Update status
            $salesOrder->status = DocumentStatus::CONFIRMED;
            $salesOrder->confirmed_at = now();
            $salesOrder->confirmed_by = $confirmedById;
            $salesOrder->save();
            
            return $salesOrder;
        });
        
        // Dispatch events AFTER transaction commits
        $this->reservationService->dispatchPendingEvents();
        event(new SalesOrderConfirmed($salesOrder));
        
        return $salesOrder;
    }
    
    /**
     * Cancel a sales order.
     * This releases all stock reservations.
     */
    public function cancel(Document $salesOrder, ?string $cancelledById = null, ?string $reason = null): Document
    {
        if (!in_array($salesOrder->status, [DocumentStatus::DRAFT, DocumentStatus::CONFIRMED])) {
            throw new \DomainException('Cannot cancel order in current status');
        }
        
        $salesOrder = DB::transaction(function () use ($salesOrder, $cancelledById, $reason) {
            $salesOrder = Document::where('id', $salesOrder->id)
                ->lockForUpdate()
                ->first();
            
            // Release all reservations for this order
            $this->reservationService->releaseBySource(
                source: ReservationSource::SALES_ORDER,
                sourceId: $salesOrder->id,
                reason: \App\Modules\Inventory\Domain\Enums\ReleaseReason::CANCELLED,
                releasedById: $cancelledById,
            );
            
            // Update status
            $salesOrder->status = DocumentStatus::CANCELLED;
            $salesOrder->cancelled_at = now();
            $salesOrder->cancelled_by = $cancelledById;
            $salesOrder->cancellation_reason = $reason;
            $salesOrder->save();
            
            return $salesOrder;
        });
        
        // Dispatch events AFTER commit
        $this->reservationService->dispatchPendingEvents();
        event(new SalesOrderCancelled($salesOrder));
        
        return $salesOrder;
    }
}
```

### 6.2 Update DeliveryNoteService

**CRITICAL:** This is the most important service. Stock decrement + COGS must be atomic with confirmation.

```php
<?php

declare(strict_types=1);

namespace App\Modules\Document\Domain\Services;

use App\Modules\Document\Domain\Document;
use App\Modules\Document\Domain\Enums\DocumentStatus;
use App\Modules\Document\Domain\Events\DeliveryNoteConfirmed;
use App\Modules\Inventory\Application\Services\StockReservationService;
use App\Modules\Inventory\Application\Services\WeightedAverageCostService;
use App\Modules\Inventory\Domain\Enums\MovementReason;
use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use App\Modules\Inventory\Domain\Enums\ReservationSource;
use App\Modules\Treasury\Application\Services\GeneralLedgerService;
use Illuminate\Support\Facades\DB;

class DeliveryNoteService
{
    public function __construct(
        private readonly StockReservationService $reservationService,
        private readonly WeightedAverageCostService $wacService,
        private readonly GeneralLedgerService $glService,
        private readonly FiscalHashService $fiscalHashService,
    ) {}
    
    /**
     * Confirm a delivery note.
     * 
     * This performs ALL of the following in a SINGLE transaction:
     * 1. Release reservations (if any)
     * 2. Decrement physical stock
     * 3. Record stock movements
     * 4. Create COGS GL entry
     * 5. Apply fiscal hash
     * 6. Update status
     */
    public function confirm(Document $deliveryNote, ?string $confirmedById = null): Document
    {
        if ($deliveryNote->status !== DocumentStatus::DRAFT) {
            throw new \DomainException('Only draft delivery notes can be confirmed');
        }
        
        $deliveryNote = DB::transaction(function () use ($deliveryNote, $confirmedById) {
            // Lock the document
            $deliveryNote = Document::where('id', $deliveryNote->id)
                ->with(['lines.product', 'location', 'salesOrder'])
                ->lockForUpdate()
                ->first();
            
            if ($deliveryNote->status !== DocumentStatus::DRAFT) {
                throw new \DomainException('Delivery note was already confirmed');
            }
            
            $totalCOGS = 0;
            
            foreach ($deliveryNote->lines as $line) {
                // Skip non-physical products
                if (!$line->product_id || !$line->product?->isPhysical()) {
                    continue;
                }
                
                // 1. Release reservation if this DN is linked to a Sales Order
                if ($deliveryNote->sales_order_id && $line->sales_order_line_id) {
                    $this->reservationService->releaseBySourceLine(
                        source: ReservationSource::SALES_ORDER,
                        sourceId: $deliveryNote->sales_order_id,
                        sourceLineId: $line->sales_order_line_id,
                        reason: ReleaseReason::DELIVERED,
                        releasedById: $confirmedById,
                    );
                }
                
                // 2. Decrement stock and capture COGS
                // recordSale already uses lockForUpdate internally
                $movement = $this->wacService->recordSale(
                    product: $line->product,
                    location: $deliveryNote->location,
                    quantity: (float) $line->quantity,
                    reference: "DN:{$deliveryNote->document_number}:L{$line->id}",
                    // Add these if WeightedAverageCostService supports them:
                    // reason: MovementReason::DELIVERY,
                    // referenceType: Document::class,
                    // referenceId: $deliveryNote->id,
                );
                
                $totalCOGS += $movement->total_cost;
            }
            
            // 3. Create COGS GL entry (inside transaction!)
            if ($totalCOGS > 0) {
                $this->glService->createCOGSEntry(
                    companyId: $deliveryNote->company_id,
                    amount: $totalCOGS,
                    date: $deliveryNote->document_date ?? now(),
                    reference: $deliveryNote->document_number,
                    sourceType: 'delivery_note',
                    sourceId: $deliveryNote->id,
                    description: "COGS for delivery {$deliveryNote->document_number}",
                );
            }
            
            // 4. Store COGS on document for reference
            $deliveryNote->cogs_amount = $totalCOGS;
            
            // 5. Apply fiscal hash
            $this->fiscalHashService->applyHash($deliveryNote);
            
            // 6. Update status
            $deliveryNote->status = DocumentStatus::CONFIRMED;
            $deliveryNote->confirmed_at = now();
            $deliveryNote->confirmed_by = $confirmedById;
            $deliveryNote->save();
            
            return $deliveryNote;
        });
        
        // 7. Dispatch events AFTER transaction commits
        $this->reservationService->dispatchPendingEvents();
        event(new DeliveryNoteConfirmed($deliveryNote));
        
        return $deliveryNote;
    }
}
```

## Architecture Notes

### Transaction Boundaries

```
┌─────────────────────────────────────────────────────────────────┐
│ INSIDE TRANSACTION (Atomic - All or Nothing)                    │
├─────────────────────────────────────────────────────────────────┤
│ • Stock reservation/release                                     │
│ • Stock quantity changes                                        │
│ • Stock movement records                                        │
│ • GL entries (COGS, Inventory)                                  │
│ • Fiscal hash generation                                        │
│ • Document status update                                        │
└─────────────────────────────────────────────────────────────────┘
                              │
                         COMMIT
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│ AFTER TRANSACTION (Side Effects - Can Fail Safely)              │
├─────────────────────────────────────────────────────────────────┤
│ • Event dispatching                                             │
│ • Notifications                                                 │
│ • Webhooks                                                      │
│ • Analytics/logging                                             │
│ • Fraud detection alerts                                        │
└─────────────────────────────────────────────────────────────────┘
```

### Why This Matters for Certification

1. **Atomicity**: If any part fails, nothing happens - prevents inconsistent state
2. **Audit Trail**: Every stock change has a traceable movement record
3. **Immutability**: Fiscal hash ensures confirmed documents can't be tampered with
4. **No Gaps**: Stock levels always match the sum of movements
5. **Traceability**: Polymorphic references link movements to source documents
