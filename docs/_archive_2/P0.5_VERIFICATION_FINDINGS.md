### 1. WeightedAverageCostService ✅ **EXCELLENT**

**Location:** `/apps/api/app/Modules/Inventory/Application/Services/WeightedAverageCostService.php`

**Methods Found:**

#### recordPurchase() - Lines 35-124
```php
public function recordPurchase(
    Product $product,
    Location $location,
    float $quantity,
    float $landedUnitCost,
```

**What it does:**

- ✅ Updates Product cost_price
- ✅ Dispatches ProductCostPriceUpdated event
- ✅ All in atomic transaction

**Strengths:**

## Recommended Approach

### Option A: Extend Existing (RECOMMENDED)

**Keep WeightedAverageCostService** and extend it:

1. **Add MovementReason parameter** (keep MovementType for backward compatibility)
2. **Add reference_type + reference_id parameters** (keep reference for backward compatibility)
3. **Create wrapper methods** for clarity:
   ```php
   public function recordGoodsReceipt(...) {
       return $this->recordPurchase(..., reason: MovementReason::GOODS_RECEIPT);
   }

   public function recordDelivery(...) {
       return $this->recordSale(..., reason: MovementReason::DELIVERY);
   }

   public function recordCustomerReturn(...) {
       return $this->recordReturn(..., reason: MovementReason::CUSTOMER_RETURN);
   }
   ```
4. **Create event listeners** to call these methods
5. **Migrate StockMovement table** to add new fields

**Pros:**
- ✅ Leverages existing excellent code
- ✅ Minimal changes
- ✅ Backward compatible
- ✅ Maintains WAC logic

**Cons:**
- ⚠️ Service name is misleading (it's not just "costing")
- ⚠️ Mixed responsibilities (costing + movement)

**Create StockMovementService** and **refactor** WeightedAverageCostService to use it:

1. **Create StockMovementService** as P0.5 specifies
2. **Inject CostingService** for WAC calculations
3. **Refactor WeightedAverageCostService** to call StockMovementService
4. **Keep existing public methods** for backward compatibility

**Pros:**
- ✅ Clean separation of concerns

- ✅ Easier to test

**Cons:**

## Decision: Hybrid Approach

**Recommendation:** **Option A (Extend Existing)** with renaming:

1. **Rename** `WeightedAverageCostService` → `StockMovementService`
2. **Keep** all existing methods (`recordPurchase`, `recordSale`, `recordReturn`)
3. **Add** new parameters (reason, reference_type, reference_id) with defaults
4. **Add** wrapper methods for clarity:
   - `increaseStock()` → calls `recordPurchase()`
   - `decreaseStock()` → calls `recordSale()`
   - `adjustStock()` → new method
   - `transferStock()` → new method
5. **Extract** costing logic to `CostingService` (internal)
6. **Add** event listeners for all document types
7. **Migrate** database schema

**Migration path:**

### Phase 2: Create MovementReason Enum (0.5 days)

```php
enum MovementReason: string
{
    // Keep existing MovementType as-is for now

    // Inbound
    case GOODS_RECEIPT = 'goods_receipt';
    case CUSTOMER_RETURN = 'customer_return';
    case TRANSFER_IN = 'transfer_in';
    case ADJUSTMENT_POSITIVE = 'adjustment_positive';
    case OPENING_BALANCE = 'opening_balance';

    // Outbound
    case DELIVERY = 'delivery';
    case SUPPLIER_RETURN = 'supplier_return';
    case TRANSFER_OUT = 'transfer_out';
    case ADJUSTMENT_NEGATIVE = 'adjustment_negative';
    case DAMAGE = 'damage';
    case EXPIRY = 'expiry';
    case WRITE_OFF = 'write_off';

    public function getMovementType(): MovementType {
        return match($this) {
            self::GOODS_RECEIPT, self::CUSTOMER_RETURN,
            self::TRANSFER_IN, self::ADJUSTMENT_POSITIVE,
            self::OPENING_BALANCE => MovementType::Receipt,

            self::DELIVERY, self::SUPPLIER_RETURN,
            self::TRANSFER_OUT => MovementType::Issue,

            default => MovementType::Adjustment,
        };
    }
}
```

### Phase 4: Create Document Event Listeners (2 days)

**ProcessDeliveryNote (CRITICAL):**
```php
class ProcessDeliveryNote
{
    public function __construct(
        private readonly StockMovementService $stockService,
        private readonly GeneralLedgerService $glService,
    ) {}

    public function handle(DeliveryNoteConfirmed $event): void
    {
        $deliveryNote = Document::with('lines.product')->find($event->deliveryNoteId);

        DB::transaction(function () use ($deliveryNote) {
            foreach ($deliveryNote->lines as $line) {
                if (!$line->product?->isPhysical()) continue;

                // Use existing recordSale method!
                $movement = $this->stockService->recordSale(
                    $line->product,
                    $deliveryNote->location,
                    (float) $line->quantity,
                    $deliveryNote->document_number,
                    MovementReason::DELIVERY,           // NEW
                    'delivery_note',                     // NEW
                    $deliveryNote->id                    // NEW
                );

                // COGS is already captured in movement.unit_cost
            }

            // Create GL entry
            $this->glService->createCOGSEntry(...);
        });
    }
}
```
