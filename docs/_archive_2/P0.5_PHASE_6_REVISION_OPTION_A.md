### 6.1 Create SalesOrderService

**File:** `app/Modules/Document/Domain/Services/SalesOrderService.php`

```php
<?php

declare(strict_types=1);

namespace App\Modules\Document\Domain\Services;

use App\Modules\Document\Domain\Document;
use App\Modules\Document\Domain\Enums\DocumentStatus;
use App\Modules\Document\Domain\Enums\DocumentType;
use App\Modules\Document\Domain\Events\SalesOrderConfirmed;
use App\Modules\Document\Domain\Events\SalesOrderCancelled;
use App\Modules\Inventory\Application\Services\StockReservationService;
use App\Modules\Inventory\Domain\Enums\ReleaseReason;
use App\Modules\Inventory\Domain\Enums\ReservationSource;
use App\Modules\Inventory\Domain\Exceptions\InsufficientStockException;
use Illuminate\Support\Facades\DB;

/**
 * Service responsible for sales order confirmation and cancellation.
 *
 * Follows the same pattern as DeliveryNoteService:
 * - All operations atomic within single transaction
 * - Events dispatched AFTER transaction commits
 * - Stock reservation integrated into confirmation
 */
final class SalesOrderService
{
    public function __construct(
        private readonly StockReservationService $reservationService,
    ) {}

    /**
     * Confirm a sales order.
     *
     * This performs ALL of the following in a SINGLE transaction:
     * 1. Validate order can be confirmed
     * 2. Reserve stock for all physical product lines
     * 3. Update document status
     * 4. Update confirmation tracking
     *
     * @throws \DomainException If order cannot be confirmed
     * @throws InsufficientStockException If insufficient stock for reservation
     */
    public function confirm(Document $salesOrder, ?string $confirmedById = null): Document
    {
        if ($salesOrder->type !== DocumentType::SalesOrder) {
            throw new \DomainException(
                'Only sales orders can be confirmed with this service.'
            );
        }

        if (!$salesOrder->isDraft()) {
            throw new \DomainException(
                'Only draft sales orders can be confirmed. Current status: '.$salesOrder->status->value
            );
        }

        // Check if auto-reservation is enabled
        $settings = $salesOrder->company->getReservationSettings();
        $autoReserve = $settings->autoReserveOnSalesOrder;

        return DB::transaction(function () use ($salesOrder, $confirmedById, $autoReserve): Document {
            // Lock the document
            /** @var Document $salesOrder */
            $salesOrder = Document::where('id', $salesOrder->id)
                ->with(['lines.product', 'location', 'company'])
                ->lockForUpdate()
                ->firstOrFail();

            if (!$salesOrder->isDraft()) {
                throw new \DomainException('Sales order was already confirmed');
            }

            // Reserve stock for each physical product line (if enabled)
            if ($autoReserve) {
                foreach ($salesOrder->lines as $line) {
                    // Skip non-physical products (services, etc.)
                    if (!$line->product_id || !$line->product?->isPhysical()) {
                        continue;
                    }

                    // This will throw InsufficientStockException if not available
                    // Transaction will rollback automatically
                    $this->reservationService->reserve(
                        product: $line->product,
                        location: $salesOrder->location,
                        quantity: (string) $line->quantity,
                        source: ReservationSource::SalesOrder,
                        sourceId: $salesOrder->id,
                        sourceLineId: $line->id,
                        createdById: $confirmedById,
                        metadata: [
                            'document_number' => $salesOrder->document_number,
                            'partner_id' => $salesOrder->partner_id,
                            'line_number' => $line->line_number,
                        ],
                    );
                }
            }

            // Update document status and confirmation tracking
            $salesOrder->update([
                'status' => DocumentStatus::Confirmed,
                'confirmed_at' => now(),
                'confirmed_by' => $confirmedById,
            ]);

            return $salesOrder->fresh(['lines']);
        });

        // Events dispatched automatically via DB::afterCommit in StockReservationService
        // Plus dispatch SalesOrderConfirmed event
        DB::afterCommit(function () use ($salesOrder, $confirmedById) {
            event(new SalesOrderConfirmed(
                salesOrderId: $salesOrder->id,
                tenantId: $salesOrder->tenant_id,
                companyId: $salesOrder->company_id,
                documentNumber: $salesOrder->document_number,
                partnerId: $salesOrder->partner_id,
                locationId: $salesOrder->location_id,
                total: $salesOrder->total ?? '0.00',
                currency: $salesOrder->currency,
                confirmedBy: $confirmedById,
                confirmedAt: $salesOrder->confirmed_at->toIso8601String(),
            ));
        });
    }

    /**
     * Cancel a sales order.
     *
     * This releases all stock reservations atomically.
     *
     * @throws \DomainException If order cannot be cancelled
     */
    public function cancel(
        Document $salesOrder,
        ?string $cancelledById = null,
        ?string $reason = null
    ): Document {
        if ($salesOrder->type !== DocumentType::SalesOrder) {
            throw new \DomainException(
                'Only sales orders can be cancelled with this service.'
            );
        }

        if (!in_array($salesOrder->status, [DocumentStatus::Draft, DocumentStatus::Confirmed], true)) {
            throw new \DomainException(
                'Cannot cancel order in current status: '.$salesOrder->status->value
            );
        }

        return DB::transaction(function () use ($salesOrder, $cancelledById, $reason): Document {
            /** @var Document $salesOrder */
            $salesOrder = Document::where('id', $salesOrder->id)
                ->lockForUpdate()
                ->firstOrFail();

            // Release all reservations for this order
            $this->reservationService->releaseBySource(
                source: ReservationSource::SalesOrder,
                sourceId: $salesOrder->id,
                reason: ReleaseReason::Cancelled,
                releasedById: $cancelledById,
            );

            // Update document status
            $salesOrder->update([
                'status' => DocumentStatus::Cancelled,
                'cancelled_at' => now(),
                'cancelled_by' => $cancelledById,
                'cancellation_reason' => $reason,
            ]);

            return $salesOrder;
        });

        // Dispatch event after commit
        DB::afterCommit(function () use ($salesOrder, $cancelledById, $reason) {
            event(new SalesOrderCancelled(
                salesOrderId: $salesOrder->id,
                tenantId: $salesOrder->tenant_id,
                companyId: $salesOrder->company_id,
                documentNumber: $salesOrder->document_number,
                cancelledBy: $cancelledById,
                cancellationReason: $reason,
                cancelledAt: $salesOrder->cancelled_at->toIso8601String(),
            ));
        });
    }
}
```

```php
public function confirm(Request $request, DocumentType $type, string $document): JsonResponse
{
    /** @var User $user */
    $user = $request->user();
    $companyId = $this->companyContext->requireCompanyId();

    // Initial existence check (without lock - for fast 404 response)
    $exists = Document::forCompany($companyId)
        ->ofType($type)
        ->where('id', $document)
        ->exists();

    if (! $exists) {
        return response()->json([
            'error' => [
                'code' => 'NOT_FOUND',
                'message' => 'Document not found',
            ],
        ], 404);
    }

    try {
        // Delegate to appropriate service based on document type
        $documentModel = match ($type) {
            DocumentType::SalesOrder => app(SalesOrderService::class)
                ->confirm(
                    Document::findOrFail($document),
                    $user->id
                ),

            DocumentType::DeliveryNote => app(DeliveryNoteService::class)
                ->confirm(
                    Document::findOrFail($document),
                    $user->id
                ),

            // For other document types, use simple confirmation
            default => DB::transaction(function () use ($companyId, $type, $document, $user): Document {
                $lockedDocument = Document::forCompany($companyId)
                    ->ofType($type)
                    ->lockForUpdate()
                    ->find($document);

                if ($lockedDocument === null) {
                    throw new \DomainException('Document not found');
                }

                // Check status inside the lock - this is the idempotency check
                if (! $lockedDocument->isDraft()) {
                    // Already confirmed - return silently (idempotent)
                    if ($lockedDocument->status === DocumentStatus::Confirmed) {
                        return $lockedDocument;
                    }
                    throw new \DomainException('Only draft documents can be confirmed');
                }

                // Update document status and confirmation tracking
                $lockedDocument->update([
                    'status' => DocumentStatus::Confirmed,
                    'confirmed_at' => now(),
                    'confirmed_by' => $user->id,
                ]);

                return $lockedDocument;
            }),
        };

        return response()->json([
            'data' => new DocumentResource($documentModel),
        ]);
    } catch (InsufficientStockException $e) {
        return response()->json([
            'error' => [
                'code' => 'INSUFFICIENT_STOCK',
                'message' => $e->getMessage(),
                'details' => [
                    'product_id' => $e->productId,
                    'location_id' => $e->locationId,
                    'requested' => $e->requested,
                    'available' => $e->available,
                ],
            ],
        ], 422);
    } catch (\DomainException $e) {
        return response()->json([
            'error' => [
                'code' => 'INVALID_OPERATION',
                'message' => $e->getMessage(),
            ],
        ], 422);
    }
}
```

```php
/**
 * Cancel a sales order.
 *
 * POST /api/v1/orders/{order}/cancel
 */
public function cancel(Request $request, DocumentType $type, string $document): JsonResponse
{
    /** @var User $user */
    $user = $request->user();
    $companyId = $this->companyContext->requireCompanyId();

    $validated = $request->validate([
        'reason' => 'nullable|string|max:500',
    ]);

    try {
        $documentModel = match ($type) {
            DocumentType::SalesOrder => app(SalesOrderService::class)
                ->cancel(
                    Document::findOrFail($document),
                    $user->id,
                    $validated['reason'] ?? null
                ),

            default => throw new \DomainException('Cancel operation not supported for this document type'),
        };

        return response()->json([
            'data' => new DocumentResource($documentModel),
        ]);
    } catch (\DomainException $e) {
        return response()->json([
            'error' => [
                'code' => 'INVALID_OPERATION',
                'message' => $e->getMessage(),
            ],
        ], 422);
    }
}
```

## Summary of Changes

### What's Different from Listener Approach:

1. ✅ **SalesOrderService** created (dedicated domain service)
2. ✅ **Stock reservation** happens INSIDE confirm transaction (atomic)
3. ✅ **InsufficientStockException** blocks order confirmation (better UX)
4. ✅ **DocumentController** delegates to services (thin controller)
5. ❌ **No listeners** for stock reservation (all in service)
6. ✅ **Events** still dispatched for audit/fraud detection

### Architecture Flow:

```
DocumentController::confirm(SalesOrder)
  └─> SalesOrderService::confirm()
       └─> DB::transaction
            ├─> Lock document
            ├─> Reserve stock (may throw InsufficientStockException)
            ├─> Update status
            └─> Return document
       └─> DB::afterCommit
            └─> Dispatch SalesOrderConfirmed event
                 └─> Fraud detection listeners (passive monitoring)
```

This matches the DeliveryNoteService pattern exactly.
