## 5. Auditor coverage delta — PASS

The hardened auditor distinguishes an OpenAPI document from a standalone schema and recursively discovers every document member named `schema` plus every `components.schemas` entry (`apps/api/tools/openapi/src/StrictSchemaTruthAuditor.php:12-55`). Its schema walker rejects boolean-true schemas, empty schemas, free objects, permissive `additionalProperties`, and unconstrained arrays (`apps/api/tools/openapi/src/StrictSchemaTruthAuditor.php:58-97`). It explicitly descends through bare property values, map-valued schema keywords, compositions, items, conditionals, and additional/unevaluated schemas (`apps/api/tools/openapi/src/StrictSchemaTruthAuditor.php:99-127`).
