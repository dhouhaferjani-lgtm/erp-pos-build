## Path A pivot (round-8)

Codex round-8 P1 surfaced that the activation hardening plan §Phase 1's compliance promise ("training receipts skip the fiscal chain") only holds for the **online** path through `ReceiptCreationService.php:466-485`. The POS is offline-first: every sale goes through `createOfflineReceipt` → `ReceiptSyncService`, neither of which consults `terminal.is_training_mode`. So training-terminal sales sync as production receipts.

The full fix is a 2-3-day architectural workstream (SQLite migration + createOfflineReceipt branching + sync payload extension + ReceiptSyncService routing + end-to-end tests). Orchestrator chose the **Path A** style pivot identical to T1.4:
1. Land PR #99 with conservative banner copy that makes no compliance promise.
2. Open T2.7 as a separate workstream for the architectural fix.
3. Add a `TODO(go-live-followup):` anchor in `createOfflineReceipt` that documents the gap inline.

- FR: "Terminal de test — vérifiez le mode avant chaque transaction."
