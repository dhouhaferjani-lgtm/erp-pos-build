**Counts:** 2 BLOCKER, 4 HIGH, 5 MED, 2 LOW.

**Worst systemic issue:** Float contamination of the inventory cost/quantity pipeline. The WAC path is float-typed end to end (`GoodsReceiptService` → `recordPurchase`/`calculateNewWAC` → `CurrencyScale::bcformat($float,…)`), so every goods receipt rebases persisted WAC through a float; the same `(float)$quantity` pattern leaks into reserved-stock increments and physical-count reconciliation that post adjustments. Secondary: layer inversion in BatchExpiry (Domain importing Application DTOs/services + the GL across boundaries) plus module-root placement.
