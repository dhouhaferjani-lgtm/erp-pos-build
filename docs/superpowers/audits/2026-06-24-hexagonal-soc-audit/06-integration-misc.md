**Counts:** 3 BLOCKER, 8 HIGH, 6 MED, 1 LOW (consolidated from ~106 callsites).

**Worst systemic issue:** These integration modules have effectively no enforced boundary or layer separation — Application services, controllers, jobs and listeners directly import, query and `::create()` other modules' Eloquent models (Product, Document, Partner, Company, StockLevel); `MarketplaceOrderService` alone writes four foreign-module entities in one method. The two platform-facing modules leak external HTTP into Application (`PlatformIntegration` injects a concrete client and calls the `Http` facade). Vehicle defines repository interfaces it then bypasses — the intended shape is understood, so the fix is consistent enforcement (HTTP ports, owning-module services/contracts) rather than redesign.
