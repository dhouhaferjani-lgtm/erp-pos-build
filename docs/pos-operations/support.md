## Remote Session Rules

1. Operator starts the remote tool only after Synerivia requests it.
2. Operator reads the session code to Synerivia through the approved channel.
3. Operator remains at the terminal and watches the session.
4. Synerivia must not copy full database backups off the machine unless required for incident response and approved by the customer.
5. Synerivia must not enable unattended access.
6. At session end, operator closes the remote tool and records the session in the support log.

## Log Bundle Command

Use this when remote access is unavailable or before escalation. The command collects logs, redacts the stored auth token, and exports the last 24 hours of `sync_log` if `sqlite3` is available.

```powershell
$CompanyId = "REPLACE_WITH_COMPANY_ID"
$Root = Join-Path $env:APPDATA "com.syneriva.izipos"
$LocalRoot = Join-Path $env:LOCALAPPDATA "com.syneriva.izipos"
$Out = Join-Path $env:TEMP ("izipos-support-{0:yyyyMMdd-HHmmss}" -f (Get-Date))
$Zip = "$Out.zip"
$Sqlite = "sqlite3"

New-Item -ItemType Directory -Force $Out | Out-Null

Copy-Item (Join-Path $Root "*.log") $Out -ErrorAction SilentlyContinue
Copy-Item (Join-Path $LocalRoot "*.log") $Out -ErrorAction SilentlyContinue
Copy-Item (Join-Path $Root "logs") (Join-Path $Out "roaming-logs") -Recurse -ErrorAction SilentlyContinue
Copy-Item (Join-Path $LocalRoot "logs") (Join-Path $Out "local-logs") -Recurse -ErrorAction SilentlyContinue

$Settings = Join-Path $Root "izipos-settings.json"
if (Test-Path $Settings) {
  $Raw = Get-Content $Settings -Raw
  $Redacted = $Raw -replace '"auth_token"\s*:\s*"[^"]+"', '"auth_token":"[REDACTED]"'
  Set-Content -Path (Join-Path $Out "izipos-settings.redacted.json") -Value $Redacted
}

$Db = Join-Path $Root "izipos-$CompanyId.db"
if ((Test-Path $Db) -and (Get-Command $Sqlite -ErrorAction SilentlyContinue)) {
  $SyncCsv = Join-Path $Out "sync-log-last-24h.csv"
  $OnceCommand = '.once "' + ($SyncCsv -replace '"','""') + '"'
  & $Sqlite $Db ".headers on" ".mode csv" $OnceCommand "SELECT * FROM sync_log WHERE created_at > datetime('now', '-1 day') ORDER BY created_at DESC;"
}

Compress-Archive -Path (Join-Path $Out "*") -DestinationPath $Zip -Force
Write-Host "Created support bundle: $Zip"
```

Email or upload the zip through the approved support channel. Do not attach a full backup unless Synerivia asks for it.

Do not include the non-log contents of `%LOCALAPPDATA%\com.syneriva.izipos` in a routine log bundle. That local app-data root contains WebView2 browser localStorage and should be shared only as part of a full approved backup/restore incident.

## Stolen Or Lost Terminal

1. Disconnect the terminal from the network if still accessible.
2. Revoke the operator account and terminal assignment server-side.
3. Preserve the latest backup if available.
4. File an incident with Synerivia and the customer owner.
5. Do not restore the terminal without a new AES key and fresh terminal pairing.
